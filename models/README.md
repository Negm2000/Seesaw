# Simulink Models

Models are grouped by purpose. `startup.m` adds this tree recursively to the MATLAB path, so models can still be opened by name when names are unique.

- `hardware_validation/` - Current hardware validation/deployment test harness.
- `hardware_validation/reference/` - Reference liftoff hardware models used for layout/organization.
- `hardware_validation/legacy/` - Older one-off hardware test models kept for comparison only.
- `controllers/pole_placement/` - Pole-placement controller deployment and historical variants.
- `templates/` - Blank/template model assets.
